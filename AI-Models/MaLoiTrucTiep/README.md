# Mô hình dự đoán trực tiếp mã lỗi

Đầu phân loại (hồi quy logistic) trên vector câu của mô hình song ngữ; dự đoán mã lỗi 1..47 từ mô tả tiếng Việt/Anh, không qua triệu chứng. Nhãn huấn luyện là nhãn YẾU (suy từ dấu hiệu văn bản), chưa phải nhãn người xác minh. Chưa tích hợp vào website. Xem `ma_loi_truc_tiep.json`.
